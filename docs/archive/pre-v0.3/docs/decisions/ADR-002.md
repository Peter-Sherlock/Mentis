# ADR-002：人的默认参与方式

| 字段 | 内容 |
| --- | --- |
| 状态 | selected（由用户方向推导的设计；不是用户逐项确认） |
| 更新 | 2026-09-27，P0.3 |
| 来源 | 用户保留参与、创造性、修改目标及无需专业术语的要求 |

## 当前设计

人可持续共同设计，重要取舍用可理解的比较展示；已授权范围内的常规动作自动推进。用户可说“不知道”“不满意”“保留这一部分”，通过小样形成偏好，不必先确定完整规格。

区分偏好、专业建议、硬要求与操作授权；用户确认偏好不是专业验证。复用已有适用授权，沉默不增加权限。选择怎样互动受任务、已有授权和成本影响，不宣称只有一种“唯一自洽”的自主档位。

## 修改与验证

初期 CLI 加实际预览即可试用。P5.2a 在首个真实闭环后收集使用反馈；P5.2 保留后期独立目标用户评价。用户输入能否纠正系统、是否过度追问、是否擅自替换偏好，均需要实际记录。

本轮把默认方式的重评时点前移，不增加逐项确认要求。历史表述见 [原记录](../archive/pre-v0.2/docs/decisions/ADR-002.md)。

## 重评条件

早期试用发现负担、控制感或偏好保真问题；出现越权或过度打断；用户提出新指令。
