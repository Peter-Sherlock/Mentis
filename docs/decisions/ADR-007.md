# ADR-007：主模型选择

## 决定

Mentis 主模型使用 **DeepSeek V4.1 Flash**（官方 API 模型 ID `deepseek-flash`，2026-09-10 发布）。接入方式为 DeepSeek 官方 OpenAI 兼容接口（`api.deepseek.com`），凭据优先通过环境变量 `DEEPSEEK_API_KEY` 提供；未定义时可从项目根目录已忽略的 `.env` 读取同名键，均不入库。不同时接第二家主模型（P2.2 边界）。

## 理由

- 用户于 2026-09-28 明确指定。
- 2026-09-28 核对的官方定价：缓存未命中输入峰段 $0.30/百万 token、谷段 $0.15/百万；输出峰段 $1.20/百万、谷段 $0.60/百万。价格可能变化，真实调用前重新核对。
- 官方 OpenAI 兼容接口降低接入成本；JSON 输出模式可支撑结构化候选。

## 备选方案

- 通过聚合网关调用：前轮对 AIHUBMIX 的只读 models 列表探测未看到 DeepSeek；该结果只说明当时这个列表的可见范围，不能证明所有网关或未来时刻均不可用。当前实现仍以用户指定的 DeepSeek 官方接口为目标。
- 换用其他主模型（GPT/Claude/GLM 等）：与用户指定不符，仅在未来能力或可用性受阻时按重评条件调整。

## 影响与边界

- 认证凭据、调用预算与可传输数据范围由用户确认后生效（本记录不保存密钥）。
- P2.2 命令要求显式 `--real`；单次诊断最多两次请求（含一次 JSON 修复），每次输出上限 2000 token、输入文本上限 25000 字符。该上限不是精确费用上限。
- 本决定不授权对外发布或向第三方传输真实用户数据；首阶段仅传输合成样例文本。

## 重评条件

- 模型能力不满足 P2.2 退出条件（结构合法但语义持续不可用）。
- 定价或可用性显著变化。
- 用户指定其他模型。

## 2026-09-28 核对更正

初始 P2.2 报告误写 API ID 为 `deepseek-v4.1-flash`，并把谷段输出 $0.60 误写为峰段；现按[官方发布说明](https://api-docs.deepseek.com/news/news260910/)和[模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)更正。此更正不改变用户选定的模型产品，只修正实际请求参数与预算依据。
