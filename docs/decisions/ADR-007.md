# ADR-007：主模型选择

| 字段 | 内容 |
| --- | --- |

| 日期 | 2026-09-28 |
| 来源包 | P2.2 |
| 直接影响 | P2.2（真实调用）、P2.3/P2.4（协作与评测）、P3.x（语义审核复用同一 Model Gateway） |

## 决定

Mentis 主模型使用 **DeepSeek v4.1 Flash**（官方 API 模型 ID `deepseek-v4.1-flash`，2026-09-10 发布）。接入方式为 DeepSeek 官方 OpenAI 兼容接口（`api.deepseek.com`），凭据通过环境变量 `DEEPSEEK_API_KEY` 提供，不入库。不同时接第二家主模型（P2.2 边界）。

## 理由

- 用户于 2026-09-28 明确指定。
- 官方定价（峰段输入 $0.30/百万 token、输出 $0.60/百万，谷段减半）适合本包的小批量诊断实验预算。
- 官方 OpenAI 兼容接口降低接入成本；JSON 输出模式可支撑结构化候选。

## 备选方案

- 通过聚合网关（AIHUBMIX 等）调用：经本机实测探测（2026-09-28，只读 models 列表），现有网关密钥均不含 DeepSeek 模型，不可用。
- 换用其他主模型（GPT/Claude/GLM 等）：与用户指定不符，仅在未来能力或可用性受阻时按重评条件调整。

## 影响与边界

- 认证凭据、调用预算与可传输数据范围由用户确认后生效（本记录不保存密钥）。
- 本决定不授权对外发布或向第三方传输真实用户数据；首阶段仅传输合成样例文本。

## 重评条件

- 模型能力不满足 P2.2 退出条件（结构合法但语义持续不可用）。
- 定价或可用性显著变化。
- 用户指定其他模型。
