## 选定方向

本地单用户、单项目、同一工作区一个写入者；Python 核心；SQLite 与本地产物；先 CLI，再轻量 Web 聊天。具体版本在实现包选择并验证。

执行端优先官方可编程接口，按能力选择 SDK/协议/CLI；接入前核对文档、认证和本机运行。不以 Computer Use 操作聊天窗口作为主方案，不承诺当前环境已支持任何接口。

## 本轮细化

P1.2 先保存最小任务、产物、评审和修订关系；P1.3 在首次价值比较后完善 SQLite 事务、迁移与恢复。早期仍需可靠记录原生任务身份、版本与未知状态；不能用后置加固为盲目重试辩护。

CLI 配合本地网页预览可以做首次真实试用。网页试验载体与 Mentis 的 P3.4 聊天 UI 分开，避免提前构建大型前端。

P1.1 建立 Git 机制后才能实现业务。当前仅授权文档修订，未初始化工程。参考 [原记录](../archive/pre-v0.2/docs/decisions/ADR-004.md)。

## 重评

接口/环境实测不支持方案，或用户明确改变形态时重评。不能仅凭文档或模型回答宣称本机兼容。
