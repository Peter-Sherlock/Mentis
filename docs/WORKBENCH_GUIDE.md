# Mentis 本地工作台 — 启动与使用（P3.4）

> v1.0（2026-10-09）。本机单用户的浏览器工作台：从自然语言目标到网页交付、反馈修订、
> 作品对比与证据查看，全部在浏览器内完成。任务记录保存在本机运行目录，关闭页面不丢。

## 1. 运行条件

| 条件 | 说明 |
| --- | --- |
| Python 3.14 | `py -3.14`（核心无第三方包依赖） |
| Codex CLI 登录态 | 执行器调用本机 `codex`（项目本地配置 `runtime/codex-home`，model=gpt-6-sol；不改全局配置） |
| 模型凭据 | `DEEPSEEK_API_KEY` 环境变量或项目根目录 `.env`（DeepSeek，评估计划/专业评审用） |
| 本机 Chrome/Edge | 交付前观察测量会调本机无头浏览器截图 |
| **联网范围** | 本地服务本身只监听 127.0.0.1，不对外；**联网只发生在两处**：Codex 执行器调用（OpenAI 账号登录态）与 DeepSeek 模型请求。页面刷新、预览、证据查看都是本地读取 |

## 2. 启动

```
py -3.14 -X utf8 -B -m mentis workbench            # 默认 http://127.0.0.1:8874/
py -3.14 -X utf8 -B -m mentis workbench --port 0   # 自动选端口（以启动打印为准）
```

浏览器打开打印的地址即进入工作台。左侧为任务列表与「发起新任务」；点击任务看详情。

## 3. 一次完整使用（对应退出条件的有界任务）

1. **发起**：左侧输入自然语言目标（如"为拾光咖啡…做一个介绍页（本地单页，含…）"）→ 点「发起任务」。
   发起是显式动作：**刷新页面不会重复发起**；服务端保证单用户同时至多一个构建。
2. **跟进**：任务详情显示状态、当前阶段、生产者活动信号、修复预算、任务库摘要、模型调用数。
   页面每 3 秒自动读取一次（只读，不影响任务）。
3. **待决请求**：Mentis 遇到只有你能定的事（审美取舍、不可验证项）会出现「待决请求」卡片，
   在输入框回答并提交。**沉默不是批准**：不回答只阻塞依赖该决定的动作，其他工作照常。
4. **交付**：构建与检查完成后状态 DELIVERED（表示初稿可看，≠最终完成或你满意）。
   「作品」区直接预览 index.html（内容哈希与字节数在旁），或新窗口打开。
5. **看变化**：发生修订时「版本对比」区可选两个版本并排预览（各带内容哈希）。
6. **看依据**：「证据」区可打开运行报告、委托与执行器公开交流、事件流、模型调用台账、状态导出；
   截图在截图区。深度时间线可另开 `python -m mentis view --run <运行ID>`（只读）。
7. **反馈/改目标**：在「继续任务」区提交反馈（进入新 brief 版本并续接修订，保留未提及部分）
   或改目标（旧版本结果不再适用，按新目标重新委托）。动作提交后后台执行，完成自动刷新。
8. **必要时**：
   - **核对确认**：执行器结局为 unknown/failed 时，先亲自核对产物与执行器状态，再选
     completed/failed 提交。unknown 不会被自动重发。
   - **撤回授权**：=已确认停止，不可逆；之后任何新委托都会被拒绝，已产出文件保留待核对。
     与"待决等待"不同：等待可以回答继续，撤回不能。

## 4. 恢复（服务重启 / 页面关闭 / 运行中断）

- 任务记录全部在 `runtime/collab/<运行ID>/`（状态、任务库、追踪、产物）；**关闭页面或重启
  工作台服务都不丢**。重启服务后任务列表自动恢复可见。
- 服务重启时正在跑的构建不受影响（独立进程）；其活动信号与阶段照常写入，服务重新可见。
- 运行中断（进程被杀/异常）后的处置（核对确认、续接、单写入锁）见
  [恢复指引](RECOVERY_GUIDE.md)。工作台内可用「核对确认」完成核对收尾。

## 5. 边界

- 本机单用户：无账户、无公网部署；页面仅 127.0.0.1 可访问。
- 前端不复制权限/验收/恢复规则：所有动作由服务端转发给真实 `collab`/`collab-resume`，
  规则仍在任务契约与 CLI 内（拒绝会如实显示）。
- "已交付"始终表示初稿可看；最终完成与满意度以你的反馈为准。
