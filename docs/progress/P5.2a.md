## 本轮变更（全部离线实现与验证）

- `mentis/field.py`（新）+ CLI `field-start` / `field-feedback`：
  - `field-start --goal "<自然语言>"`：一次被归档的真实使用会话——FieldSession 目录（`runtime/field/<会话ID>/`）自动采集**实际操作**（命令+时间戳）、**系统行为**（stdout 逐条留痕 + 运行记录中的委托/时长/用量/决策分流）、**总耗时**、**阻塞与等待**（待决请求列出并标"沉默≠批准"、执行器 unknown/failed）；结束打印三入口；交互模式下当场收集满意/原话/阻塞点（可跳过）。
  - `field-feedback --run <运行目录> --satisfied yes|no --quote "<原话>" [--block "<原话>"]`：查看作品后的补记——逐字原话写入运行目录 `field-feedback.md` 并经 P1.2 契约 `record_user_feedback` 绑定该运行最近的已完成尝试（持久化往返验证）；**零尝试的运行（如待决中）不伪造契约绑定**，反馈只入档案并明确标注。
  - **研究者提示与系统贡献分列**：使用记录中"研究者提示"段记开发者提供的固定入口命令；"系统行为"段全部来自运行记录并带 provenance（agent_selected/user_selected 计数）；用户原话单独成段。
- 版本 0.8.0，阶段入口改为 P5.2a。
