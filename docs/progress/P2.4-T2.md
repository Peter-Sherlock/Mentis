## 本轮变更

- `mentis/executors/codex_cli.py`：
  - 默认走 **Popen 逐行流**（`_PopenStream`：stdout 队列线程 + stderr 独立线程 + 截止期轮询，超时杀进程）；**注入 runner 走兼容路径**（同步等待 + 结束后逐行回调），既有 FakeRunner 测试零改动通过。
  - `CodexTaskSpec.on_event(event, meta)` 回调：每条可解析事件即时回调；`meta.first` 标记首事件并携带 `first_event_latency_s`（进程启动→首事件）。回调异常不中断执行。
  - `CodexTaskResult` 新增 `first_event_latency_s`、`stderr_tail`（有界）。分类逻辑统一到 `_classify`（终态/锁/unknown 语义与 P3.1 完全一致：收到进展事件≠成功）。
  - `describe_capabilities`：`streaming_to_caller` 从 unsupported → `line_stream_with_callback (T2)`。
- `mentis/collab.py` / `mentis/guidance.py`：委托时传入 `on_event`，把执行器事件**即时**写入 trace——首事件发 `executor.started`（含首事件延迟），其后发 `executor.item`（命令/最终消息有界摘要；推理条目只记类型不入内容）。
- `mentis/trace.py`：`format_event` + `follow_timeline`（只读跟随：重放已有事件→逐条跟随→`run.finalized`+manifest 后自动结束；**兜底**：manifest 存在且事件流连续 4 轮静默也按收尾结束——探针/旧写入器直接 finalize 的场景，实测发现并修复）；Ctrl+C 仅停止读取。
- `mentis/field.py`：委托前打印 `[运行目录]` 与 `[实时旁观]` 命令（进入 tee 日志）。
- `mentis/__main__.py`：`trace --run <dir> --follow`。版本 0.10.0。
