# P3.1：第一执行器与产物观察接口

日期：2026-09-28｜状态：**completed（接口与隔离探针）**。本包证明任务、事件、文件和静态截图能进出 Mentis；不证明网页质量、交互行为或完整指导闭环。

## 本轮范围与实现

- [Codex CLI Adapter](../../mentis/executors/codex_cli.py)：使用 `codex exec --json` / `codex exec resume`，记录 Mentis task/attempt ID、brief 版本、原生 thread ID、事件序列、用量、最终文本与 Git 脏文件；只在 `turn.completed` 且进程成功、JSONL 有效时标记完成。委托不自动重试。
- 写入任务以工作区哈希取得排他锁；超时结果为 `unknown` 并保留锁，需先核对执行器与文件，不盲目重发。子进程环境移除 `*_API_KEY` / `*_TOKEN` / `*_SECRET` / `*_PASSWORD`，避免把 Mentis 的 DeepSeek 凭据传给 Codex。文件型秘密仍要求使用隔离工作区；沙箱写权限不等于完整读隔离。
- [浏览器观察器](../../mentis/browser_observation.py)与 `py -3.14 -m mentis observe-page --page <HTML>`：本地 Chrome/Edge 的独立无界面配置，采集桌面 1280×800 和移动 390×844 的初始截图，记录 HTML SHA-256、截图路径、尺寸与限制。无点击或提交自动化。
- 版本升为 0.5.0，阶段入口改为 P3.1。没有接入第二执行器、部署或完整会话编排。
