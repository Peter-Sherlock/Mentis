## 变更

- `mentis/contracts.py`：语义枚举（Provenance 三分来源、notify/request、尝试状态含 unknown、审核处置、授权状态）与最小对象（Brief、DelegationPolicy、Authorization、Interaction、ExecutionAttempt、Artifact、Review、RevisionRecord）及契约异常。
- `mentis/session.py`：TaskSession 以**操作强制不变量**——update_brief 生成新版本不覆盖旧版；notify 一律无阻塞字段；answer 来源白名单（user / existing_authorization），不存在"沉默回答"方式；dispatch 校验策略、未决请求与有效授权；accept 要求 完成+检查通过+当前 brief 版本；unknown 只能经 confirm_outcome 转换，无自动重发途径；用户满意单独记录。
- `mentis/persist.py`：会话与 JSON 无损往返（含契约版本校验与 id 计数器重建）。
- `mentis/export.py`：同一份数据渲染 Markdown——目标版本、来源标注条目、策略、授权、交互（未回答标"沉默不构成批准"）、执行/产物/审核/用户反馈三态分离、修订链。
- `mentis/demo_contract.py` + CLI `demo-contract`：脚本化演示（明确标注），真实写出样例页与 JSON/MD 到 runtime/demo/，包含两条拒绝路径；版本升至 0.2.0。
- `tests/test_contracts.py` 13 项不变量检查；test_entry 随入口更新。

过程中真实运行发现并修复 2 个问题：export.py 未导入 Provenance（NameError，演示运行暴露）；修订链测试夹具未录入带来源条目导致断言失败（测试问题，非实现问题）。
