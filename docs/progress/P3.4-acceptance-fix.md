- 修复：`_run_segment` 允许至多两段的子路径（仍拒绝反斜杠、`..`、隐藏段、空段）；`_serve_preview` 将 `versions/<名>` 解析到运行目录 `versions/`，单段名解析到 `workspace/`，目录即白名单（`trace/` 经 preview 不可达）；`_serve_evidence` 白名单含 `trace/events.jsonl`、`trace/model-calls.jsonl`、`trace/stages.jsonl`，其余两段拒绝。

### 修复二：撤回/停止/在途语义（审计 #3）

- 三状态分开显示（任务详情新增一行）：**授权**（有效 N 项/已全部撤回/无记录）、**停止请求**（无/已请求——进行中的轮次无法中断）、**已确认停止**（是=WITHDRAWN 终态，任何新委托被拒）、任务进行中（在途）。三者不再混用：撤回授权在 idle 任务上仍产生已确认停止；对进行中任务，界面提供**请求停止**（只标记意愿、可逆、不中断轮次），动作（反馈/改目标/核对/撤回）全部禁用。
- 在途识别跨服务重启：在途 = 本服务构建/动作子进程存活，**或**活动信号 fresh 而无本服务存活动作子进程（心跳不随服务进程消失，覆盖重启后的孤儿构建与 CLI 构建）。停止请求标记写在工作台自有目录（`runtime/workbench/`），**不写运行目录**（单写入不破例）。
- 动作串行：`run_action` 新增在途拒绝（409，提示改走请求停止）；既有逐运行动作锁保持。核验：真实任务 idle 时动作可用、停止按钮不显示（截图 04-three-states-delivered.png）；离线回归覆盖 fresh 拒绝、重启后新实例拒绝、stale 恢复、标记与投影、idle 拒绝停止请求、三状态投影。

### 修复三：写接口来源与媒体类型校验（审计 #4）

- `do_POST` 新增 `_write_guard`：`Content-Type` 必须 `application/json`（允许 charset）→ 否则 415；携带 `Origin` 时必须与本机服务同源 → 否则 403；无 Origin 的本机工具调用放行（Host 校验仍在）。`/api/start`、`/api/task/<id>/action`、`/api/task/<id>/stop` 全部覆盖。
- 真实核验（对运行中服务，零 spawn）：`text/plain` 写请求 415（审计实测曾 200）；外来 Origin 403；本机 JSON 200/409 正常；停止请求 text/plain 415。
