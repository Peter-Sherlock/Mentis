## 本轮变更

- **异常收尾（故障加固）**：
  - `mentis/collab.py` / `mentis/guidance.py`：`run`/`resume`（guidance 另含 `reverify`）意外异常时 `_finalize_on_error`——仍处 `dispatched`/`running` 的尝试改记 **unknown**（无执行器终态，不判失败、不假完成）、写 `run.finalized`（status=failed，含异常原文有界）、状态落盘 **ERROR** 并 finalize manifest、既有终态不覆盖不重复判定，随后重抛；CLI 层（`collab_cli.py`/`guidance_cli.py`）打印短消息不再抛裸 traceback。
  - **顺带修复一个真实缺陷**：`collaboration_from_state` 未设置 `_finalized_emitted`——任何从 state.json 恢复的 collab 运行在收尾时必然 AttributeError（T1 引入、既有测试未覆盖恢复后收尾路径）。修复 + 回归测试（`test_feedback_revision_continues_timeline_on_same_thread` 在修复前会因 AttributeError 失败）。
  - `mentis/field.py`：`field-start` 全程异常收尾——状态 `SESSION_ERROR`，usage-record 标注"**记录不完整**（半份日志如实保留，不补写未发生事件）"，证据入口永久保留 session-log.txt 日志入口；Ctrl+C 同样收尾。`field-feedback` 异常（如空原话）也收尾落盘，不再留半开日志。
- **敏感字段规则**（`mentis/trace.py: redact_text`）：已知字段名（api_key/token/secret/password/credential/authorization/密码/密钥/令牌/凭证）的 `key=value`/`key: value`/`"key": "value"` 赋值与 `Bearer <令牌>` → 值 `⟨已隐去⟩`，`emit` 时对 summary 生效。**明确不隐去** `input_tokens` 等用量计数（契约要求数据，真实运行冒烟确认 `input_tokens: 69259` 原样保留）；Bearer 先于 KV 规则处理（否则令牌残留）；prompt 归档**不脱敏**（哈希=发送文本，本地私有层）。不做广泛秘密识别承诺（契约 §6）。
- **导出白名单**（新 `mentis/trace_export.py` + `mentis trace --run <目录> --export [路径]`，格式 `mentis-trace-export/1`）：事件仅契约 §2 字段（附加字段剔除）；manifest 委托台账只含 `prompt_sha256` 不含本地路径；refs 只留 role+文件名+哈希；排除用户逐字反馈/工作区全文/prompt 原文/原生原始行。**旧记录兼容导出**：无 trace/ 的历史运行导出 `mode=historical`（现存材料视图 + unrecorded 缺口），不回填。
- **多 attempt 连续时间线**：`render_timeline` 新增委托台账（attempt→终态、thread、prompt 哈希）；`run.resumed` 标注**中断区间**（与上一事件间隔秒数，"期间无记录，不回填"）。
- **执行器原生错误保留**：`codex_cli.py` 捕获 `error`/`turn.failed` 原生 message 有界存入 `CodexTaskResult.native_error` 并拼入 FAILED 判定文本——落实契约 §7"配额类错误原文入 summary"（此前 P3.1 起只留"未报告成功终态（退出码 N）"，限额原文丢失）。

## 未验证与限制（如实）

- **异常收尾路径未经真实故障触发**：ERROR/unknown 收尾由注入式夹具证明；真实运行中的意外异常（磁盘满、权限拒绝等）表现属后续观察。
- **敏感字段规则只覆盖事件 summary 与导出**：终端实时输出（notify 打印）不经 redact——本就本地显示；stderr 尾部入 result 诊断层不自动显示。不承诺识别任意秘密（无广泛扫描）。
- **field-start 的 SESSION_ERROR 收尾依赖 collab 自身异常先落盘**：若异常发生在 Collaboration 构造之前（如工厂本身抛错），无关联运行目录，usage-record 如实写"无关联运行目录"。
- 委托台账来自 manifest——**manifest 未 finalize 的中断运行**台账缺失（回放仍显示事件流），如实呈现不推测。
- 整页真实委托下的 `--export` 未运行（避免无意义真实调用）；导出逻辑经离线夹具与 T2 探针运行核验。
- T4（真实使用核验：用户能独立回答五个问题）未开始；P5.2a 仍等待负责人真实操作记录。
