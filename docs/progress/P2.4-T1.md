## 本轮变更

- `mentis/trace.py`（新）：`TraceWriter`（events.jsonl 追加、seq 运行内单调且续接续排、UTC 毫秒时间、attempt/brief/thread 关联、refs 哈希、manifest 含 integrity 完整性；委托台账从事件重建以覆盖恢复场景）；`archive_prompt` **字节级写入**（不经 newline 转换，文件 SHA-256 = 实际发送文本哈希——Windows `write_text` 的 \r\n 转换会破坏一致性，被测试捕获后修复）；`render_timeline`（新运行事件流回放 + 完整性标注）与 `render_historical`（历史运行列现存材料+未记录缺口，**不回填、不生成 trace/**）。
- `mentis/collab.py` 接入点：运行初始化（goal.recorded / policy.set / authorization.granted）、每次委托前 `archive_prompt`（失败→尝试记 failed、执行器不被调用、delegation.prepared status=failed 留痕）、执行器终态（executor.completed，status 按 §7 映射）、硬要求复检（review.recorded）、决策请求/回答/分流（decision.*）、撤回/改目标/反馈（authorization.revoked / brief.updated）、收尾（run.finalized + manifest，每次 _persist 刷新）；`collaboration_from_state` 恢复时续排并发 run.resumed。
- `mentis/guidance.py` 接入点：冻结/策略/授权、每次观察（observation.structure / observation.render，测量 JSON 哈希引用）、诊断（observation.diagnosis）、委托（同上，prompt=指令全文）、复检与复核重检（review.recorded，引用复检文件哈希）、收尾与恢复。
- `mentis/__main__.py`：`trace --run <运行目录>`（无效目录 exit 2）。
- 版本 0.9.0。
