## 2. 真实浏览器会话（退出条件核验）

登记预算（`runtime/observability/p34/budget.json`：执行器 turn ≤4 / 模型请求 ≤12 / 墙钟 ≤120 分钟）内，用 ZCode 内置浏览器驱动工作台页面完成一次真实有界任务（运行 `20261009_095200-eebf`）：

1. 浏览器内表单发起「焦糖苹果拿铁上新介绍页」→ 真实 Codex 构建（构建中面板即显示已写出的产物与 fresh 活动信号）。
2. 执行器 `turn.completed` 但有失败子项 → **如实 unknown**（非超时）；以用户身份核对产物：内容做成了素材里的手冲工作坊，不含目标产品 → **工作台核对确认 failed**（不符尝试不复活、不自动重发）。
3. 工作台提交**反馈**纠正 → 原生线程续接修订（revision-b2）→ 检查通过 → **DELIVERED**；修订产物标题「焦糖苹果拿铁｜拾光咖啡周末限定」，含供应/周末限定（旧快照无）。
4. 看结果（预览+新窗口）、看变化（A=旧快照 8d435772… / B=当前 8ab1b070…）、看依据（报告/交流/事件流/模型台账/状态导出）全部在页面内可操作。
5. 用量：执行器 turn 2/4、模型请求 3/12（全部真实、0 Mock）。

退出条件逐项：用户无需逐项专业审批（全程只有一次待决答复与一次核对）；刷新不重复提交（重载 5+ 次、服务重启 3 次，任务唯一）；关页面不丢记录（全部在运行目录）；待决只阻塞依赖动作；异常后可见已保存作品与最后可靠状态（UNKNOWN/ERROR 提示条+核对确认入口）；专业配置/调用/产物版本可核对。

## 3. 会话中发现并修复的缺陷（先复现后修复，均有离线回归）

1. **详情面板 3 秒全量重绘打断输入与点击**（重绘竞态：答复框文字丢失、点击落在被替换节点）→ 数据指纹门控 + 输入中不重绘 + 重绘保留输入值/焦点。
2. **IAB/无头环境对原生 `confirm()` 自动取消** → 核对/撤回改页内两步确认（首次点击进入待确认态，再次点击才提交）。
3. **CSP `script-src 'self'` 拦截内联 onclick**——所有任务动作按钮从未生效（发起按钮因走表单提交而幸存）→ 改事件委托（监听静态 `#detail` 容器）。
4. 版本对比 A 帧 src 不随程序设值同步 → 显式设置。
5. **`_codex_processes_since` 把常驻 `codex-code-mode-host.exe` 误当写入者**（同 V2 app-server 类，存活门控误报风险）→ 排除项 + 回归断言（test_eval_review.WriterGatePrecisionTests 扩展）。

## 5. 诚实边界

- 「刷新不重复提交」由显式 POST + 单构建守卫保证；同一浏览器多标签同时点发起也只会创建一个构建（服务端守卫），但页面间的选中状态不同步（单用户场景影响有限）。
- 版本对比是并排预览（各带哈希），不做行内 diff；行内对比沿用 `mentis view` / versions 文件。
- 工作台不新增权限语义：核对确认的正确性仍取决于使用者真的核对过产物（页面提示如此声明）。
- 会话中的构建轮 unknown 是执行器真实行为（失败子项）；修订轮达到交付标准，专业评审为模型辅助判断，未构成专业效果验证。
- 待决答复、撤回在真实会话中未触发（无待决出现；撤回语义由 S4/P1.4 真实+离线证据覆盖）。
