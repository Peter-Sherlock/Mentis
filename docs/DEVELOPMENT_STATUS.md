## 3. 下一步与体验主线

P2.2 进行中：网关、结构观察器与诊断候选已离线验证（`py -3.14 -m mentis diagnose --page runtime/demo/event_page_v1.html --fixture tests/fixtures/mock_diagnosis_response.json` 是 Mock 链路）。真实调用尚无 `DEEPSEEK_API_KEY`。CLI 现在需要显式 `--real` 才向官方 API 发送选定页面的结构、目标、反馈与规则；单次诊断最多两次请求，每次输出至多 2000 token，输入文本至多 25000 字符。此为单次边界，非精确美元上限。真实模型返回后还须用独立可核查材料评价语义，不能仅凭 JSON 合法结案。P2.2 达到退出条件后的下一包是 **P3.1（第一执行器与产物观察）**，再到 P2.3。

体验主线当前位置：诊断链路（观察→候选→校验→拒收）可亲自查看，但内容为 Mock；真实模型响应待凭据。后续为 给出目标 → 自主产出首稿 → 自行检查修订 → 必要节点介入 → 查看结果与依据。用户可随时插话、暂停或共同设计。
