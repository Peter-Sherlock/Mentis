## 3. 下一步与体验主线

当前体验入口（P5.2a）：**`py -3.14 -m mentis field-start --label <标签> --goal "<你的原话目标>"`** —— 自然语言目标 → 自主委托 → 三入口 → 当场逐字反馈，全程自动采集操作/系统行为/耗时/阻塞（[使用指南](field-session-guide.md)，含零成本的"先看后评"路径 B：对既有真实运行 `field-feedback --run <运行目录> --quote "<原话>"`）。技术入口 `collab` / `guide-revise` / `guide-resume` 继续可用（见 P3.2 记录）。

体验主线当前位置：**给出目标 → 自主产出首稿 → 自行检查修订 → 查看结果与依据** 已由系统真实走通（P2.3/P3.2 各有真实运行）；P5.2a 检查的是**项目负责人本人**能否走通这条路并低负担表达反馈——入口已交到负责人手里，等待真实操作记录。

## 4. 尚未解决

- 全部案例与量表仍 pending_human；无新增人工专业或独立复核。正式评测前必须补足，不能由 AI 一致性检查替代。
- 正式评价用的冻结页面、样例及事件轨迹尚未制作；runtime/demo 页面只是脚本化契约演示产物。P3.1 另有隔离的 Codex 小型真实产物，但它不是冻结网页评测样本。
- Windows 上的双视口静态截图已实测；交互自动化、运行输入导出与实际答案隔离仍未实现。
- 模拟反馈阈值、必要介入机会/配对控制、强提示词基线和评分锚未校准；见 WQ-1—9、EQ-1—9。
- 已验证本机 DeepSeek 接口认证和 Codex ChatGPT 登录；费用硬上限、质量收益、跨领域与目标用户体验仍未验证。
- 正式指标阈值、样本规模与工期未冻结，不能把九类十一实例写成验证结论。
- **P2.3 架构性限制（部分已解）**：同步 CLI 单 turn 上限 600 秒 < 整页构建耗时；P3.2 中修订类委托（改现有页）实测 122 秒可完成，构建类委托仍需 unknown→核对路径或异步/分段策略（P3.3 前）。移动端溢出自动测量已实现（P3.2）；交互自动化（点击/提交的真实网络行为）仍未实现。
- **观察链更正（P3.2）**：无头 Chrome 500px 最小窗宽曾使移动截图成为 500 布局的裁剪假象；已修复（iframe 包装）。凡引用 2026-09-28 之前移动截图的视觉结论需按新采集重验。
- 决策分流为确定性关键词规则（变更动词+保留名词/新事实提示），有误判风险；模型复查与诊断同源（deepseek-flash），独立性未建立——两者都需在 P2.4 多案例上检验。
- **P3.2 验收后边界**：待决路径只证明"暂停且未委托、沉默≠批准"，不证明该请求"确实必须由用户决定"；真实改善是单案例，不外推为指导能力普遍成立；测量未知（报错/视口不符/缺截图）与复查无法绑定当前产物时判定为 unverified，不判通过——该判定路径有离线测试，未经真实触发。
- **P5.2a 缺口**：无任何真实使用记录（操作/耗时/阻塞/控制感/原话均空）；完整委托路径（field-start→真实 Codex）未真实触发；反馈仅"满意+逐字原话"两个契约字段，控制感依赖自述。负责人操作前不得进入 P2.4 的真人反馈吸收，缺数据处留空。
- 模型诊断候选只记录不自动执行；持久化存储未接（P1.3）。P1.2 契约为演示级实现（授权按 scope 精确匹配等）；远程仓库未创建；提交身份为仓库本地占位，待用户偏好后可改。
- 领域资源为模型知识草案（pending_human），未经人工专业复核；执行与静态截图接口尚未进入缺口分流闭环；声明冲突检测依赖注册表声明，动态冲突检测未实现。
- **P2.2 专业判断仍待验证**：真实模型的字段完整请求仍可能是不必要提问，部分层级判断缺视觉依据；需要 P3.2/P2.4 的独立评价，不因本轮技术接通而宣称“专家 Agent”成立。
- **P3.1 观察边界**：双视口静态截图已接通，但点击、表单提交、对比度和自动横向溢出测量仍未实现；Chrome file:// 不证明部署行为。Codex CLI Adapter 无中途输入/审批往返、token/货币硬上限，超时后按 unknown 保锁。
