## 3. 下一步与体验主线

当前体验入口：`py -3.14 -m mentis diagnose --page runtime/demo/event_page_v1.html --fixture tests/fixtures/mock_diagnosis_response.json` 是 Mock 链路；真实模型使用同一命令的 `--real` 且需要环境变量或根目录 `.env` 提供 `DEEPSEEK_API_KEY`。`py -3.14 -m mentis observe-page --page runtime/demo/event_page_v1.html` 可独立生成双视口初始截图，不触发模型计费。真实 DeepSeek 响应暴露正文漏传与无谓提问，正文遗漏已修复；实际网页截图显示移动端文字截断。Codex CLI Adapter 的隔离探针验证了任务、事件、续接和文件，但尚未接到 Mentis 的自主决策流程。**下一包 P2.3**。

体验主线当前位置：真实模型诊断与真实执行器/截图接口分别可用，尚未串成“给出目标 → 自主产出首稿 → 自行检查修订 → 必要节点介入 → 查看结果与依据”。P2.3 负责首次接线；用户仍可随时插话、暂停或共同设计。

## 4. 尚未解决

- 全部案例与量表仍 pending_human；无新增人工专业或独立复核。正式评测前必须补足，不能由 AI 一致性检查替代。
- 正式评价用的冻结页面、样例及事件轨迹尚未制作；runtime/demo 页面只是脚本化契约演示产物。P3.1 另有隔离的 Codex 小型真实产物，但它不是冻结网页评测样本。
- Windows 上的双视口静态截图已实测；交互自动化、运行输入导出与实际答案隔离仍未实现。
- 模拟反馈阈值、必要介入机会/配对控制、强提示词基线和评分锚未校准；见 WQ-1—9、EQ-1—9。
- 已验证本机 DeepSeek 接口认证和 Codex ChatGPT 登录；费用硬上限、质量收益、跨领域与目标用户体验仍未验证。
- 正式指标阈值、样本规模与工期未冻结，不能把九类十一实例写成验证结论。
- 模型与执行器分别接通但尚未由最小入口编排；持久化存储未接。P1.2 契约为演示级实现（授权按 scope 精确匹配等），未经真实闭环检验；远程仓库未创建；提交身份为仓库本地占位，待用户偏好后可改。
- 领域资源为模型知识草案（pending_human），未经人工专业复核；执行与静态截图接口尚未进入缺口分流闭环；声明冲突检测依赖注册表声明，动态冲突检测未实现。
- **P2.2 专业判断仍待验证**：真实模型的字段完整请求仍可能是不必要提问，部分层级判断缺视觉依据；需要 P3.2/P2.4 的独立评价，不因本轮技术接通而宣称“专家 Agent”成立。
- **P3.1 观察边界**：双视口静态截图已接通，但点击、表单提交、对比度和自动横向溢出测量仍未实现；Chrome file:// 不证明部署行为。Codex CLI Adapter 无中途输入/审批往返、token/货币硬上限，超时后按 unknown 保锁。
