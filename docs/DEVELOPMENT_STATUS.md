- Windows 上的双视口静态截图已实测；交互自动化、运行输入导出与实际答案隔离仍未实现。
- 模拟反馈阈值、必要介入机会/配对控制、强提示词基线和评分锚未校准；见 WQ-1—9、EQ-1—9。

- 正式指标阈值、样本规模与工期未冻结，不能把九类十一实例写成验证结论。
