## 3. 下一步与体验主线

本轮文档检查已完成，下一工程包为 P1.1：在用户指令进入工程范围时，初始化本地 Git、建立文档基线和忽略规则、Python 最小入口及必要检查。无需重新逐项批准已明确的产品方向；网页领域仍 proposed，但不阻塞领域无关的最小工程。进入领域资源实现前按届时用户指令落实试点范围，不伪造确认。

P1.1 交付应提供可运行入口、简单操作与实际输出；开发 Agent 执行验收，不要求用户实际操作后才算完成。后续体验主线：给出目标 → 自主产出首稿 → 自行检查修订 → 必要节点介入 → 查看结果与依据。用户可随时插话、暂停或共同设计。
