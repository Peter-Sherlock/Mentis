## 3. 下一步与体验主线

P1.1 已完成：Git 基线与最小入口可用（运行方式见根目录 README）。下一包 P1.2：轻量任务与反馈契约——保存 brief、来源与偏好、动作目的、原生尝试身份、产物/评审版本及前后关系，增加最小 DelegationPolicy（代决范围、保留决定、执行范围/预算、介入触发、来源与版本）与 InteractionRecord（notify_progress / request_decision、阻塞依赖、回答来源）；区分 user_selected、agent_selected、provisional。退出条件见开发计划 §4。按 AGENTS.md 第 6 节，P1.2 交付应包含用户可亲自完成的一次操作及实际输出；开发 Agent 执行验收。

体验主线当前位置：第一条可亲自运行的路径已建立（能运行入口看到版本与阶段）；后续为 给出目标 → 自主产出首稿 → 自行检查修订 → 必要节点介入 → 查看结果与依据。用户可随时插话、暂停或共同设计。
