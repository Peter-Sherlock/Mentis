# P5.2a 使用指南：把 Mentis 交给项目负责人真实使用一次

> 本文件是**研究者提示**（由开发 Agent 提供的固定入口说明），不是系统自主行为。
> 你的操作、系统的行为、你的原话会分别记录；P5.2a 的证据只能来自你本人的真实操作。

## 这轮要回答什么

在工程加固前检查：**你**能否有效委托、低负担地查看结果、并保有控制。不要求已完成完整界面——CLI 就是当前入口。

## 路径 A：完整委托（真实费用，约 5—15 分钟）

前提：Codex 已登录（本机 ChatGPT 账号）、项目根 `.env` 有 `DEEPSEEK_API_KEY`。无货币硬上限，用量会逐项记录在报告里。

```
py -3.14 -m mentis field-start --label 我的第一次委托 --goal "用你自己的话说目标，例如：给周末的读书会做一个报名页，要温暖一点，能填姓名和电话"
```

- 目标请**用你自己的话说**，不要整理成规格——这正是要测试的。
- 运行中系统会自主做常规专业决定（每条带来源标注）；只有触及保留事项（改价/改期/发布等）才会停下问你，沉默不会被视为同意。
- 结束后会打印三个入口：
  - **看结果**：作品 HTML 绝对路径（可直接用浏览器打开）；
  - **看变化 / 看依据**：`runtime\collab\<运行ID>\report.md`。
- 打开作品看完后，同一个终端会问你三句（都可直接回车跳过）：整体满意吗？你的原话？哪里被卡住/不明白？
- 产物与记录都在本地 `runtime\`（不入 Git）；你的原话逐字入档，绑定当次运行。

## 路径 B：先看后评（零成本，用已有的真实运行）

已有真实产物（P2.3/P3.2 的运行，未改动）：

- 拾光咖啡 v2（P3.2 修订后，移动端首屏含价格）：`runtime\guidance\20260928_092745-5465\v2\index.html`
- 修订前 v1 对照：同目录 `v1\index.html`
- 变化与依据：`runtime\guidance\20260928_092745-5465\report.md`

看完后提交你的真实反馈（原话逐字记录）：

```
py -3.14 -m mentis field-feedback --run runtime/guidance/20260928_092745-5465 --satisfied no --quote "你的原话，例如：移动端价格是看见了，但插画太小气" --block "哪里卡住或没看懂，原话"
```

路径 B 也是真实使用（查看+反应），P5.2a 会如实区分"完整委托自用"与"仅查看反馈"两种深度。

## 记录了什么、在哪

| 内容 | 位置 |
| --- | --- |
| 你的操作命令、系统全部输出、耗时 | `runtime\field\<会话ID>\session-log.txt` |
| 使用记录（操作/系统行为/阻塞/研究者提示分列） | `runtime\field\<会话ID>\usage-record.md` |
| 你的原话（逐字）与满意标注 | 运行目录 `field-feedback.md` + 会话记录 `session.json` |
| 系统贡献（委托、自主决定、修复） | 运行目录 `report.md`（看依据，带 provenance） |

`runtime\` 不入 Git；如需保留到仓库证据，明确允许后由开发者摘录归档。
